# Deployment Configuration

## Project Type
Standalone Excel Dashboard

## Deployment Method
Manual download and local execution.

## Environment Requirements
- Windows or macOS computer.
- Microsoft Excel or a compatible spreadsheet application.
- Access to the project workbook.

## Deployment Steps
1. Download `Simple_Profit_Analysis.xlsx` from the GitHub repository.
2. Save the workbook to the local computer.
3. Open the workbook in Excel.
4. Navigate to the Profit Summary worksheet.
5. Verify that the KPIs, category summary, chart, and business insights are displayed correctly.

## Hosting Requirements
No web server, cloud hosting, database server, or application deployment is required.

## Configuration
No environment variables, API keys, or external services are required.

## Verification
Confirm that the workbook opens successfully and the dashboard displays the expected profit figures.

Note: This project is an Excel workbook, not a deployed web application.
